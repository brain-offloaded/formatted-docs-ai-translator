현재 앱에는 텍스트 번역만 있어. 이제는 이미지 번역을 새로 만들 거야. 기존 구조를 최대한 유지하는 것이 목표해야 해. 단, 이미지의 특성상 프롬프트 등의 부분에는 의도적인 변화가 있을 거야.
또, ocr을 위해서, 다음 json response를 사용하게 해줘.

{

  "properties": {

            "type": "string",
            "description": "html styled text"
          },
          "box_2d": {
            "type": "array",

              "type": "number"
            }

          }
        },
        "required": [
          "rich_text",
          "box_2d",
          "label",
          "language",
          "font_size"
        ]
      }
    },
    "translated_result": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
